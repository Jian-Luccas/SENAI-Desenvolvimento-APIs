# SENAI-Desenvolvimento-APIs
API REST em ASP.NET Core para listagem de projetos utilizando Entity Framework Core e SQL Server.

# Exo.WebApi

Projeto desenvolvido para a disciplina de Desenvolvimento de APIs (SENAI).

## Tecnologias

- ASP.NET Core 6
- Entity Framework Core
- SQL Server
- C#

## Funcionalidades

- Conexão com SQL Server
- Método GET para listagem de projetos
- Retorno dos dados em JSON
